# BioCarta - Исправления

## Проблемы и решения

### 1. ❌ Сайт показывал "Not Found"
**Причина**: Статические файлы не раздавались из-за неправильного пути в `backend/main.py`

**Решение**: Исправил путь к static директории:
```python
static_dir = os.path.join(os.path.dirname(os.path.dirname(__file__)), "static")
if os.path.isdir(static_dir):
    app.mount("/", StaticFiles(directory=static_dir, html=True), name="static")
```

### 2. ❌ Логотип не отображался
**Причина**: Файл logo.png не загружался корректно

**Решение**: Убрал логотип полностью, оставил только текст "BioCarta":
- На странице входа: крупный градиентный заголовок (42px)
- В навигации: текст с жирным шрифтом (20px)

### 3. ❌ Иконка графика выглядела устаревшей
**Причина**: Использовался старый эмодзи 📊

**Решение**: Заменил на медицинский стетоскоп 🩺 с полупрозрачностью для более современного вида

### 4. ⚠️ Файлы загружаются, но не парсятся
**Статус**: Требует дополнительной диагностики

**Возможные причины**:
- База данных не инициализирована правильно на Render
- Отсутствуют seed данные (biomarkers, references, synonyms)
- Проблемы с парсингом PDF/XML файлов

**Следующие шаги**:
1. Проверить логи Render после деплоя
2. Убедиться, что база данных создана и заполнена seed данными
3. Протестировать загрузку файлов после деплоя
